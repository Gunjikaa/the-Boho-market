# The Boho Market

A beautifully handcrafted e-commerce marketplace celebrating bohemian style, sustainable living, and ethical artistry.

## Features

- Responsive product catalog with filtering and search
- Shopping cart with calculations
- Blog section with articles
- Contact form and FAQ
- Wishlist functionality
- Account management pages

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons

## Project Structure

```
the-Boho-market/
├── index.html
├── order-confirmation.html
├── pages/          (Product, blog, and shop pages)
├── assets/
│   ├── css/       (Stylesheets)
│   ├── js/        (JavaScript files)
│   └── images/    (Product and category images)
├── .gitignore
└── README.md
```

## Getting Started

1. Clone the repository
2. Open index.html in your browser
3. Or use a local server: `python -m http.server 8000`
